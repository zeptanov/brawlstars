# Maze Royale

Динамичная многопользовательская RPG-арена в процедурном лабиринте: туман войны,
стрельба, лут, сужающаяся зона и один победитель (или одна команда).

## Возможности

- Процедурные лабиринты трёх размеров (41 / 61 / 81 клетка).
- Оружие с разбросом, перезарядкой и разным темпом стрельбы.
- Пикапы: аптечки, щиты, ускорение, невидимость, радар, патроны.
- Сужающаяся зона с этапами и уроном; матч идёт около 3–4 минут.
- Режимы: «каждый за себя» и «команды 2×2» (побеждает команда, где кто-то выжил).
- Настройки комнаты: количество ботов, сложность, темп зоны, размер карты,
  количество лута, дружественный огонь, видимость для мёртвых и возрождение
  союзников через 6 секунд (по умолчанию выключено).
- Ограниченное зрение: и игроки, и боты видят только в радиусе обзора и по линии
  прямой видимости — сквозь стены и туман стрелять нельзя.
- Наблюдение после смерти: «только туман» вокруг выбранного игрока или вся карта.
- После матча — возврат в лобби комнаты без пересоздания и повторный старт
  с другими настройками.
- Страница гайда с правилами, описанием оружия и бонусов и мини-обучением.
- Боты с BFS-навигацией, стрейфом, сбором лута и разной сложностью.

## Управление

| Действие | Десктоп | Мобильные |
| --- | --- | --- |
| Движение | WASD / стрелки | левый виртуальный стик |
| Прицел | мышь | правый виртуальный стик |
| Огонь | ЛКМ / пробел | кнопка «Огонь» |
| Рывок | Shift | кнопка «Рывок» |
| Перезарядка | R | кнопка «Перезарядка» |
| Пауза / меню | Esc | кнопка меню |
| Таблица | Tab | кнопка таблицы |
| Смена цели наблюдения | Q / E | кнопки на экране |

Режим управления определяется автоматически; в настройках можно принудительно
выбрать сенсорный или мышиный вариант.

## Мультиплеер по локальной сети

1. Хост нажимает «Создать комнату» — сервер поднимается прямо в приложении.
2. Остальные игроки выбирают «Присоединиться»: комната находится автоматически
   широковещательным запросом (UDP, порт обнаружения `47780`), либо вводится
   IP-адрес хоста вручную (игровой порт `47777`).
3. В лобби хост настраивает матч и запускает его. Клиенты могут подключаться
   и во время боя — они появятся внутри текущей зоны.

Ограничения:

- Мультиплеер работает только в одной локальной сети; интернет-игра не
  поддерживается.
- В веб-версии `dart:io` недоступен, поэтому LAN-игра отключена — доступна
  только тренировка с ботами.
- Для Android/iOS/macOS сетевые разрешения уже прописаны в платформенных
  конфигах; при первом запуске iOS запросит доступ к локальной сети.

## Офлайн-тренировка

«Тренировка с ботами» поднимает тот же авторитетный сервер внутри процесса,
без сокетов. В настройках главного меню выбираются формат боя, сложность,
размер карты, темп зоны, лут и видимость для мёртвых.

## Разработка

```bash
flutter analyze
flutter test
flutter run -d windows   # или chrome / android / ios
flutter build windows
flutter build web
```

Проект не использует сторонних pub-зависимостей: только Flutter SDK.

## Архитектура

- `lib/game/` — генерация лабиринта, симуляция, оружие, пикапы, зона, боты.
- `lib/net/` — протокол (JSON), авторитетный сервер, клиент, UDP/LAN-транспорт.
- `lib/app/` — комната, настройки сессии, тема.
- `lib/ui/` — главное меню, лобби, игровой экран, HUD и отрисовка арены.

Сервер авторитетен: клиент отправляет только ввод, а сервер фильтрует видимость
и рассылает каждому игроку персональный снапшот (античит для тумана войны).
